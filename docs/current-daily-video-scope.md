# 現在の依頼に基づく日次動画の制作先

旧保護設定の復旧と、本人が現在指定した8チャンネルの制作先の確認を分ける。
正規guardは、次の条件を満たす制作日のディレクトリとその配下だけを確認する。

- 現在の継承担当2906の登録先、固定した仕様のパスと本文SHA、実際のCC repository originを照合する。
- 制作先は `D:/CC/Work/youtube-daily/<既知channel>/<公開日>` とする。
  現在依頼より古い10月18日以前、未知チャンネル、当日から3日以上先は対象にしない。
- 対応する正規ToDoのproject、題名の日付、既知のchannel ID、保存仕様内のmanifest先を照合する。
  未検証の復旧行、本人停止、dispatch無効、別の登録先では成立しない。
- ToDoのjobs履歴にある実jobのIDとcwdを照合する。従来の日次launcherはproject/todo_idを
  jobへ記録していないため、ある場合だけ追加照合する。架空の値を元jobへ補わない。
- 元のdeny、実体と全祖先のreparse検査、現在の担当の停止を保持する。
  新規manifestの原子的保存は、既に確認できた親の新しいleafだけに認める。

親の制作領域一覧、旧の日付、未知の資源、私的な設定や認証があるTools配下を一括で認めるものではない。
元の保護名簿を復旧済みとは扱わず、映像・音源・品質・予約・公開の成功も別に確認する。
8チャンネルの通常の日次制御と投稿経路をそのまま使用する。
担当2906や制作ToDoが完了した後も、確認済み成果の修正・保管と継続する日次運用に
同じ現在の依頼を使う。本人停止や登録変更は拒否し、確認していない過去の成果へ広げない。
