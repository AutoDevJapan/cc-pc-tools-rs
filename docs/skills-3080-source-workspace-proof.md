# Source準備の宣言パスと実行パスを照合する

Windowsでは、準備時に宣言した作業パスと実行メタデータの作業パスが、
同じ場所を指しながら区切り文字や大文字・小文字の表記だけ異なる場合がある。
従来の受領処理は、元の準備呼び出しを実行メタデータの表記で再生成したため、
正しく記録された呼び出しとの完全一致を失っていた。
逆に、準備結果の宣言だけを書き換えたケースも検出できなかった。

実行パスとの場所の一致は従来どおり確認し、呼び出しの完全一致には、
独立した正常ツール結果に記録された宣言そのものを使用する。
コマンドやworkdirの表記は正規化せず、宣言との差分を許容しない。
元の呼び出し、準備結果、spec、nonce、物理オブジェクト、作者、世代、時間窓を保つ。
後続イベントも含むsnapshot全体の検査、重複の拒否、通常の結果受領は変更しない。

回帰テストは、実行パスの表記だけが異なる正例と、宣言の後付け変更、
別の場所、コマンドだけの変更、workdirだけの変更を拒否する反例を確認する。
通常の配布更新に必要な既存Windows版の識別情報は、
[候補生成前の同buffer観測](evidence/skills-3080-guard-before-source-receive.json)に保持する。
