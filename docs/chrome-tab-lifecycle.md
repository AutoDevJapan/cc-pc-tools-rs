# Chromeの作業タブの寿命

作成成功の記録があるタブだけを閉じる。URL、題名、グループから所有者を推測しない。

- ブラウザを使わない予定のminimalジョブも、軽量なRustの中継と環境変数を持つ。後からChrome操作を始めても作成記録に入る。ブラウザ用のNodeプロセスを追加で起動する変更ではない。
- Codexの作成成功応答を、担当へ返す前に保存する。担当が応答を待たず切断しても、受信中の作成応答を最大4秒待って記録する。
- 保存に失敗した作成はタブを閉じて取り消し、担当へ成功を返さない。取り消しが通信障害で失敗した場合は、書き込めるときに別の記録用フォルダーへ保存して回収する。壊れた再試行記録や履歴への書込失敗があっても他のタブの回収を続ける。
- シェル、子担当、定期処理は `owner_chrome open <ジョブID> <URL>` を使う。Claudeの直接作成と「タブが無ければ作成」はRustのPreToolUseフックが記録する経路へ案内する。`owner_chrome install-claude-hook` で既存設定を保って追加する。
- 成功、失敗、取消し、lostを回収する。再実行待ちで担当プロセスが無ければすぐ回収し、監督プロセスが生きていても保持しない。再開した別の試行のタブも回収する。
- 実行中はタブ作成から30分以上経ち、担当のイベントとChrome操作が30分以上更新されていなければ回収する。順番待ちの監督による生存報告は操作と見なさない。状態の破損・読取失敗は回収の許可に使わない。
- タブの記録にあるChrome拡張の識別子と世代を照合する。接続先が消えたり別のプロフィールが見つかったりした場合、全接続先から一致するものを探す。一致する接続先がない場合は記録を保持して再試行する。
- 失敗回数を `chrome-retries` に保存する。3回失敗したものは毎分の処理が「後片付けの記録」へ1件にまとめて通知なしで投稿する。投稿に失敗した場合も次回再試行する。
- 古い試行順に回収し、切断したプロフィールが他のタブを妨げないようにする。時間・件数の上限で残ったものはdeferredを記録する。
- 閉じた、または既に閉じていた記録は `chrome-tab-history` に残す。毎分の処理と終了処理は同じロックを使う。

## 通常の接続情報と個別終了

`owner_chrome open` は、その実行中ジョブの通常のBrowser Use中継が受け取った
attach成功応答に対応する接続情報だけを再利用する。実session・turn・Chromeの
instance/generationが一致し、記録から60秒以内の情報を使う。通常の
`getNetworkPolicy` が合成した制約とrequest header設定を変更せず渡し、
未取得・別session・期限切れではcreateTabとattachの前に失敗する。
空の許可policyを生成したり、別sessionとして接続したりしない。
終了・別turnへの移行・detachの失効世代はジョブ内の共有記録へ保存し、
送信時の世代をattach応答時とcontext読込時にも照合する。
終了前に送ったattachの遅延成功応答はcontextを再作成できず、
released tabをclaimする前にも有効なcontextとChrome identityを確認する。
この記録を取得する中継はジョブの監督プロセス内で動くため、CLIだけの更新では
既に動く旧監督プロセスへ新しい記録機能は追加されない。

旧CLIが作った専用session（`cc-chrome-<UUID>`、turn `open`）の個別終了では、
同じChrome identityとsession内の対象1枚だけを確認してから通常のfinalizeを使う。
複数枚・所有解放済み・世代変更は終了を拒否し、成功後も全体inventoryで不在を確認する。
keep指定は従来の終了要求と同じ優先順位で保持する。
保存失敗に伴うrollbackも成功・既存不在の履歴を残し、履歴保存が失敗した場合は
emergency記録を残して既存の回収処理へ引き継ぐ。

## 原因を確認した記録

2026-10-08の調査で直近2日分654ジョブを走査。成功したChrome作成101回のうち9回（5ジョブ）で記録用フォルダーが無かった。5ジョブはすべてminimalでChromeの中継が無かった。終了処理を毎分へ後回しにしたジョブは9件。読めないジョブ、イベント、監督ログは0件。単純な文字列検索の数字は実行回数に使っていない。

再実行待ち4ジョブは監督だけが動き、古いタブ9件を保持していた。実Chromeの識別子・世代・タブIDと照合すると9件は既に閉じており、記録を整理した。別の作業中2件も実Chromeにない。記録に無い既存タブは操作していない。

調査証拠はPCの `D:/CC/Tools/rs/verification/chrome-tab-leak-2021` に保持する。ログの内容、認証値、ページの題名・URLはGitHubへ載せない。

## 検証

再実行待ち、30分の境界、最近の操作、古い試行、lost、再試行の永続化、3回後の無通知投稿、切断後の作成応答、別プロフィール、記録の無いタブの保持を検査する。配備後はテスト用ジョブで作った `about:blank` のタブを、終了時と毎分の処理で回収し、所有していないタブのID集合が変わらないことを照合する。
