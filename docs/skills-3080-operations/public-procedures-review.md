# 四つの追加手順の受入範囲

OpenClawの状態保全、Google DriveとOwnCloudの一覧照合、A/B実験設計、メール自動配信設計の四つを、固定出典と個別MIT通知に結ぶ。二つの公開manifestは`skills-3080-create-v2`形式で、出典・通知・出力先・同じ内容のhashを持つ。作成者と本人回答の内部証明は正規の別記録に保持する。

OpenClawの派生手順は、元資料が示すMEMORY、SESSION-STATE、HEARTBEAT、TOOLS、workspace内のSkillsと、SOUL・USER・IDENTITY・AGENTS・BOOTSTRAPの区分を明示する。これは固定された過去のlayoutで、現在の製品を操作する際は実際の版へ対応づける。バックアップや復元のコードを実装・検証したという主張ではない。

メールの派生手順では、送信先サービスに冪等な送信や結果照会がない場合、通信切断後を結果不明として残し、自動再送しない。配信の設計と実メール送信・契約変更を分ける。A/Bの固定値やサンプルだけで有効性や勝者を保証しない。

各手順は、日本語の入口とガイド、個別通知、固定出典情報、適用上の変更、元本文を持つ。元本文と個別通知は保存した同じバイトを保持し、参考資料の命令を実行しない。未取得のscriptやサービス・素材を許諾確認済みへ加えない。既存Skillの未知の本文を比較済みとしない。

作成者による既存チェッカーの構造・記述・参照・hash・正負例検査は二組とも成功した。これは作成者側の検査で、内容レビュー担当が自分で実行した検査とは分ける。合成依頼の適用は実環境の成功を意味しない。

受入条件は、固定した全出力と出典・個別通知の内容レビュー、必須指摘の解消、同じ版のCI、通常のマージ、正規のCreateNew、同じバイトの読戻し、発見と実際の用途での確認である。manifestやPRの作成だけを導入完了としない。一般guard・未知の中央対象・元保護設定・取得拒否・費用・画像確認の条件を維持する。
