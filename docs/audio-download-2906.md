# 制作担当2906の通常ダウンロード1件を分類する

ToDo2954は、既存Web生成と通常Downloadを記録した制作担当2906の
音声1ファイルだけを、当日制作2895へ渡すための修復である。
Downloads全体、ElevenLabs全体、過去の音源、原保護台帳を許可しない。
`original_registry_recovered=false` は維持する。

既存の通常分類へ、Goの `audio2906PathAllowed` を追加する。
入力パスは固定した1件との完全一致を先に検査する。
原除外はすべて優先し、既存の未知資源の保護を変えない。

判断の独立した根拠は、修復元から提示された生成・通常Downloadの
操作記録の固定SHA256と、担当2906の固定spec、制作2895の固定spec、
元の398文字台本のSHA256である。パスやハッシュを呼出元から受け取らない。
元の操作記録には物理IDがなく、2954が内容を開かずに取得したID・volume、
作成・更新・変更時刻、サイズ、所有者SID、リンク数1を追加照合した。
この追加観測をダウンロード当時に取得済みだったとは扱わない。

通常の登録root・Git origin、元ToDo・停止状態・同日制作ジョブの所有も確認する。
分類対象を2026年10月20日の同一制作先に固定し、10月21日JST以降は許可しない。
担当が別になった場合やspec・元操作記録・台本の改変、置換・ハードリンク・
junction・reparse point・所有者変更は拒否する。

音声の識別に使うWindowsハンドルの権限はFILE_READ_ATTRIBUTESとREAD_CONTROLだけ。
音声本文・ハッシュ・probe・decode・copyを分類に用いない。
操作記録と台本は独立した固定SHAを照合する。
最後に現物メタデータ・資格・除外・リンクを再確認する。
これは読み取り専用の分類であり、その後の一般のファイルアクセスと
完全に原子的なトランザクションではない。制作側も使用直前の通常guardを確認する。

検査は合成した通常ファイルと注入した資格だけで行う。
実音声や原保護名簿はテストで読まない。
変更パッケージの `go test -race ./...` と `go vet ./...`、正式CI、
別モデルレビューを通し、通常merge後の最新mainから正式guardへCAS配布する。
配布後の対象false・対照trueと、制作担当の実読み取り・probe・受理が完了条件。
音声の再生成、動画完成、全動画公開はこの修復の完了と区別する。
