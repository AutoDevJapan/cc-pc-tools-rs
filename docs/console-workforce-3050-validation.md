## 変更した動作

- 互換欄 `workers` のToDo行と、単独ジョブの行を分けて数える。読み取れない行は未知の行として残す。
- 原記録の各集計を足し合わせない。復旧未確認、依存待ち、起動待ち、根拠不明の停止を別に返す。
- 実作業の判定は、正規collectorのキー・識別一致・30秒以内の処理・待機なしを必要とする。本文・heartbeat・最終文章だけから算出しない。
- 部分取得で個別に確認できた件数は保持するが、総数はnull。未知・古い・未来の取得時刻を現在の0件へ置き換えない。
- 進捗nullと記録済み0、記録更新と最終成果時刻を区別する。
- 元の常駐snapshotから `workforce` を一度作り、表示用3パネルが同じ取得世代を共有する。パネルごとの原データ走査を追加しない。
- 常駐側では実作業の別観測元をまだ接続していないため、実作業の件数はnull、Native Codex/Claudeも未観測として返す。外部cacheがあるだけで接続済み・全PC集計とは扱わない。
- 新しい射影は固定の状態語彙と数値の参照だけを出す。元の本文・任意の名称・パス・自由なエラー文を返さない。
