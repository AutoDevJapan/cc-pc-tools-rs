# 参照からの制作とSkill化の3案

提供済み参照の制作指示、美術案の改訂、動作を確認したWeb表現のSkill化という3つの手順を固定入力にした。原3本文、支持2本文、作者MITを通常判定後に同じSHA・Git blob・長さ・UTF-8へ照合して全文読了した。元177件の既読範囲内なので、新しい全体読了数へ加算しない。

実装済みの仕組みと未実装の資料、UI画像への本人回答、固有素材の利用条件、実績・価格・顧客等の事実を分けた。五案固定、無条件の日次化、Chrome禁止、全件private配備、古いtool名、割合や4変更による独自性保証は採用していない。新しい名前・製品方向・価格や推薦を勝手に創作しない。

原例の名前とプロンプトは作者の架空例として原文に保持する。本人の製品名や採用案にはしない。未保存の画像・validator・元デモ・第三者参照は取得、同梱、実行していない。root MITは選択した作者の文書へ個別に対応させ、素材・字体・人物・サービスへ包括していない。

new:false/not_checked_in_memory_onlyは配置前のin-memory scaffoldの状態であり、中央に同名の対象が存在するという観測ではない。正式レビュー後の用途を限定したCreateNewで対象不在を確認する。未知の本文を一括で読んだり、重複と断定したりしない。

公開bundleが構造テストの再現入力で、結果は3案PASS。未配置・未採否で全16資料は継続する。正式な別モデルレビュー、通常配置、返却実体、発見と実適用を確認してから導入台帳へ反映する。元資料の伏字・未読の意味は、原文保存ファイルの秘匿や削除を意味しない。
