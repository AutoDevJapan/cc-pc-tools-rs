## ほかのToDoの完了を待つ（2026-10-08）

- ほかのToDoの完了だけを待って担当が終了するときは、必ず `D:/CC/Tools/todo/todo.exe wait <自分のToDo番号> --on <待ち先の番号>` で記録する。複数なら `--on` を繰り返す。実測済みの進み具合は `--progress <0〜100>` も指定する。
- 「ToDo番号の完了待ち」とメモに書くだけで止めない。オーナーの判断待ち用の `block` を完了待ちに使わない。待ち先がすべてdoneになるまで担当は自動起動されず、完了すると通常の実行枠で再開する。
- 待機中は待ち先の状態を確かめるだけの担当を繰り返し起動しない。担当履歴・指示・作業場所を保持して再開する。自分自身・循環待ちは登録できない。
