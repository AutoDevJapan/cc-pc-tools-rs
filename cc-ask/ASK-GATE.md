# 作業の許可を質問しないための関所

`ask` は題名と本文の全文を、設定・モデルの文章点検・添付処理・Discord通信より前に調べます。
「許可」「承認」「してよいか」などと、Chrome・計測・ログイン・検査・ビルド・一時ファイル・片付け・共有枠・再試行・続行などの語が組み合わさり、オーナーの判断事項がなければ送信を止めます。
終了コードは78、標準エラーに「聞かずに進めること」を返します。`--dry-run` にも同じ判定を適用します。

お金・公開・権利・顧客への約束・製品の方向性・取り消せない操作は通します。
単なる背景の「公開サイト」「所有権の試験」「支払いを調べる」や案件名は、判断事項とみなしません。
語による判定に曖昧さがある本物の質問は、次の指定で送れます。

```text
discord_ask.exe ask --agent Codex --title "月額料金を決めてください" --body-file question.txt --owner-only money
```

指定できる理由は `money`、`publish`、`rights`、`customer`、`direction`、`irreversible` の6種類です。
質問の状態記録の `owner_only` に保存します。本文には何を決める必要があるかを具体的に書きます。
通常の作業許可を送るためには使いません。

## 追加質問の前に元の回答を読む

同じ元ToDoに本人回答がある場合、新しい判断範囲の質問も、最初の呼び出しでは投稿せず `owner_context_required` を返します。元質問、本人回答、本人ID、Discord APIからの取得元、日時、元ToDoの指示参照先を担当が確認してください。AIが選べる技術的詳細は質問せず進めます。

本当に対象・仕様・危険範囲が新しい判断だけ、返された `owner_context_digest` を判断JSONの `reviewed_owner_context` に添えて再実行します。これは担当が既存回答を読んだ記録であり、新しい操作への本人承認ではありません。回答の変更で記録は失効します。同じ判断は、この指定があっても再投稿しません。

範囲が不明な `decision_scope_required` でも元質問と本人回答を返します。`approval_matches_requested_scope: false` の回答を、新しい範囲の承認に読み替えないでください。照会は配送や実反映の記録を進めません。

`audit-history --thread <ID>` を繰り返して最大10件の履歴だけを点検できます。`--capture` を省くと質問・受領記録を変更せず、他の履歴を探索しません。`deliver-reply` は検証した返信を元ToDoの既存作業指示にも一度だけ保存します。依存待ち・担当・進捗を保ち、保存と実反映を分けて記録します。既存の巡回と質問・無通知進捗投稿の分離は維持します。

判定は固定規則で完結します。既存のllm-jpによる日本語点検は補助のまま、送信可否を変更しません。
許可を求めていない通知や、本人の端末で必要な一手の依頼を、一律に止めるものではありません。

## 過去の題名による検証

2026-10-07時点の状態ファイル335件を取得しました。題名132種類を別モデル（Claude Sonnet 5.5）が読み、通常の作業20種類、本人の判断83種類、題名だけでは不明29種類に分けました。
案件名は既存のクライアント一覧で除去し、個人の返信・本文・IDは保存していません。

再現用入力は `tests/fixtures/ask-history-20261007.json` です。`cargo run -p cc-ask --example ask_gate_audit` で各題名の判定と集計を出せます。
題名だけに許可表現がないものは本文なしでは断定できません。この群も通しすぎとして数えた上で、送信時には必ず本文も調べます。

調整後は335件中8件を止め、327件を通しました。明示的な不要許可質問の通過は0件、本人の判断質問の誤停止は0件です。
通常作業に見えるが題名に許可表現のない13件（12種類）は通過し、本文がないため未判定として残します。
「支払いを調べてよいか」を支払いの決定と誤認しないよう、支払・課金・購入・契約は意思決定の語との組み合わせへ調整しました。
「任せてよいか」「使う許可」、本番検査の起動修正、所有権の試験への注記も回帰検査に含めました。
別モデルレビュー後、動詞を固定列挙せず「て/でよいか」などを拾う形へ変更しました。
本文の括弧内を判定から消さず、題名の先頭の案件名だけを除去します。
否定形、非公開、月額0円・予算内の背景説明、一時ファイルの完全削除を本人の判断と誤認しない例も追加しました。
本番への配備、画面案、英語の費用・公開表現も調べ、追加費用なしで公開だけを相談する場合などは通します。
