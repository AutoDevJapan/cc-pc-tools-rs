# 保存済みメタデータの有限走査

[集計データ](skills-3080-saved-metadata-census.json)は、元の固定資料を変更せずに追加で確認した結果を示す。

固定した6mile/skillsの204,532記述子から、`/_meta.json`で終わる52,665件を最後まで走査した。
328個の記録ファイルの前後hashと全順番、各記述子の出典・固定版・path・SHA・Git blob・bytes・保存先・役割を独立照合した。
この工程はmetadataの機械解析であり、主手順の意味評価や利用許諾、導入へ加算しない。

機械的に解析したのは52,663件、開く前にguard実行版が変わって保留したものが1件、原資料の形式異常が1件である。
後者は136 bytesの原資料と記述子のhashが一致するが、UTF-8として不正でNULを1 byte含み、UTF-16のBOMもない。
原本を変更せず、文字コードを推定して成功へ付け替えない。
前者の保留は再取得・別経路読取をしていない。

過去の最初の190解析記録には保護判定の詳細が保存されていないため、後からその値を補わない。
今回の照合で分かる原資料の同一性と、保存されていない過去の判定内容を分ける。

許諾に関連する英語keyは計21箇所で、公開可能な定数としてMITが18、MIT-0が3だった。
これは許諾の主張を分類した数であり、個別の権利や作者を確認した数ではない。
metadataにkeyがない候補にも本文・別の通知に条件がある可能性があり、無許諾や除外の判断へ変えない。
その他の値、実担当、内部specや実行記録は公開データへ含めない。
全16資料・73,220候補の本文評価と有用な手順の配置は同じ作業で続ける。
