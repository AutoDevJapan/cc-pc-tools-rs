# Xのブックマークを毎日1回整理する

このジョブは既存の日次処理を実行する担当であり、日次タスクや別の調査担当を作らない。
最初にPCの現在のAGENTS.mdとD:/CC/Policies/owner-agent-conduct-20261021.mdを読む。
元の対象・本人の既存回答を保持し、通常の読取・検査・ログインを許可待ちへ変えない。
カード情報、指示のない受託部製品、新しい支出は扱わない。

1. shared-todo、local-console、social-media-research、knowledge-to-skills、japanese-report-writing、現在のbrowser/computer-use Skillを読む。
2. 元ToDo、D:/CC/Tools/x-bookmarks/done.txt、該当するruns/YYYY-MM-DD.jsonを読む。
   旧未完了があればその選択と途中結果を保持し、完了済みの試用や反映を繰り返さない。
   欠落した過去の記録を空にしたり、別名の台帳で置き換えたりしない。
3. ログイン済みの本人Chromeに自分のタブを作り、XのBookmarksを表示順に読む。
   /i/historyへの転送はBookmarksタブを確認する。既存タブ・グループは変更しない。
   doneの投稿IDと既存Skillの出典URLで判明した重複を除き、未処理10件を1回分とする。
4. 全文、画像、スレッドと公開一次資料を確認し、事実・意見・未確認を分ける。
   紹介されたツールは既存枠または無料の基本操作を実際に試し、結果と限界を保存する。
   新しい支出・カード入力・投稿・無関係な公開へ進めない。
   必要な無料登録や既存アカウントの通常ログインは、本人へ許可を聞き直さず進める。
5. D:/CC/Skillsの適合する既存Skillへ知見・具体手順・検査・固定出典を反映し、読み戻す。
   原版を.trashへ保全し、使える知見がない投稿を無理にSkillへ変えない。
   紹介された有用なGitHubは既存のchrome-bookmark-queueへ保存し、created/existsを確認する。
6. 保存・試用・読み戻しの条件がそろった正規URLだけをdone.txtへ重複なく追記する。
   その投稿のブックマークを解除し、Bookmarkへ変わったことを画面で確認する。
   日次runsへ表示順、反映先、試用、未確認、GitHub保存、解除の実結果を記録する。
7. 作ったタブを工程終了時に閉じ、元ToDoを実際の達成に応じて更新する。
   正常完了を含む全終了・待機・拒否結果を主へ返す。主が永続保存してDiscordへ記録する。
   登録・起動・実処理・検査・配布を区別し、件数を推測しない。

実行審査に拒否された具体操作だけを、拒否文と残作業を添えて主へ返す。
同じ拒否を別経路で迂回せず、独立した作業は続ける。
