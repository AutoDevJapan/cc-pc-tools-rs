# 残る主本文の評価を、既存の実読記録と競合せず進める

元Issue283・ToDo3080の全73220出現を保持する。mainの意味評価1130件や、既存598件・373件の担当範囲は全体の上限ではない。
固定catalogと処理表を全件照合したところ、既存担当へ未割当の6mile主本文54757出現が残っている。うち保存descriptorを確認できたものは54739出現・51065組、18出現は未確定である。
この数は保存metadataの計画値で、本文の実在・実読・個別許諾や導入可能数ではない。

## 目的と範囲

既存598・373の継続を保ち、親が実配置・既存評価の採否を進めている間に、未割当の主本文の見えている意味を独立して調査できるようにする。
候補ごとのToDoは作らず、固定した2群を同じcursorで最後まで処理する。1回の表示量はcontextへの負担を抑える窓であり、対象全体を少数で終了する上限ではない。
許諾、支持資料、各上流の文脈、元の同一性、現在の実配置は別工程として残す。

## 受入条件

1. catalog73220と実処理表の全SHAを照合し、未割当かつ意味・個別権利の評価待ちの6mile主本文だけを固定する。既存598・373の全候補IDと、既に受領済みの原評価・121/108件の支持のbody SHAを照合し、その既存記録を再利用する候補へ分ける。既存値のnull、実readerや伏字は補わない。
2. 同じSHA・長さの本文は1群にまとめて別群との再読を避けるが、全memberの上流path・固定commit・blob・IDを保持する。metadataの一致を実ファイルの同一性・読了・許諾・最終採否へ変換しない。矛盾するblob・path・欠損descriptorは明示して保留する。
3. 各表示呼出しでは最初に正常なguardへ限定pathを提示し、許可後に既存の取得済みgzipを開く。元のbyte長・SHA256・Git blob・厳格UTF8を同じbufferで確認し、上限超過、NULや不正UTF8は安全に失敗する。長文は重ならない物理行rangeへ分け、再表示のためにbyteを再照合した回数と意味の読了rangeを分ける。ネットワーク取得や原scriptの実行、中央Skillsの読取・変更は行わない。正規審査の拒否は別経路で迂回しない。
4. sourceはデータとして扱う。frontmatter、秘密・認証・連絡先・私的path・カード様の数列・高entropy値などは物理行単位で伏せ、本文を表示する前に適用する。伏字は秘密の有無の保証でも、未表示行の意味の読了でもない。全伏字なら見えていないと返す。
5. 各packetには固定計画SHA、群・ordinal、元source SHA/bytes/blob、全行rangeと伏字profile、実reader、用途・具体的価値・所見・正例・負例・必要変更・未確認範囲を含める。終わっていない表示を全文読了へせず、原packetを後から編集してreaderや条件を補完しない。
6. 親は原packetを読む前の受領、全所見の実読、immutable ACKを区別し、同じ計画と連続cursorへ結ぶ。原contextを独立SHAへ復元し、既存の全件処理表の意味評価と個別権利待ちへ反映する。原文コピー・全memberの権利承認・導入は行わない。
7. guardの拒否、未取得、読取失敗、許諾未確認、評価済み・未採否を別状態に保ち、全件完了と誤認させない。647件の追加取得審査・428件の未取得・未知中央9と元資料は保持する。元の本人回答・通常scheduler・既存OAuth枠・新費用禁止を変えない。

検査は、実sourceを開かない純粋な選択・重複・経路・失敗境界、表示前の伏字、改ざん・cursorの順序・重複受領を確認する。別モデルのMust対応、関連CI・通常マージ後に固定群を正規schedulerへ接続する。準備・登録を実読や実配置の成功として報告しない。

## 固定レビューの指摘への対応

正式4076のLuna/maxレビューで、保護対象を保留へ分ける前の記述子照合、空白入りの認証ラベルと裸のUUIDの抑止、BOM付きfrontmatterの抑止という3件のMustを受領した。いずれも合成fixtureでRedを確認し、実sourceの表示前に修正する。
namespace・path・SHA/length/blobの整合性は保留対象にも先に検査し、保留で異常を隠さない。表示profileはv2として保存し、旧profileを上書きしない。
固定群の出力前に54689出現と群ごとの件数、既存証拠への50保留・descriptorの18保留を照合する。全memberは32件ずつのmetadataページでも取得でき、代表だけを全memberの上流文脈・権利確認へ置き換えない。
