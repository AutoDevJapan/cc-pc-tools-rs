# 元1171の固定質問に付く旧投稿への参照

Issue478/ToDo3751の実配送で、質問の予約後に送信元の照合が失敗した。
現在の送信先は、新しい質問・進捗の投稿と、明示した本人の元依頼に限られる。
固定の元スレッドは旧ボット投稿であり、一般の送信先として追加しない。

固定normal-ask要求、sender要求、元スレッド、入力SHAを専用の読取検証へ結ぶ。
元1171と担当3277の正規3638/3650証拠・元仕様・実job・現在の停止を再確認し、
予約中の同じ質問の本文・decision・題名・待機指定と一致する場合だけ出所の参照を許す。
元投稿はAPIで同じguild/forumの実ボットの投稿と照合する。
元投稿へ新しいメッセージを送らず、新質問と通知なし進捗の中に元URLを保持する。
新しい質問・進捗とそのリンクの投稿先制限、秘密判定、本人メンションの規則は維持する。

受入条件:

- 同じ固定入力の通常askが元の識別を保持し、新質問と別の進捗だけへ配送される。
- 他の要求・元スレッド・本文・decision・actor・project・仕様・本人停止を拒否し、POSTしない。
- 同じ入力の再実行で新しい質問やメンションを増やさない。
- 質問の回答と3277の既存依存待ちはPR479の対応をそのまま使う。
- 旧投稿へのPOST/PATCH、一般の旧質問の再開、Stripe操作は許可しない。
- 失敗の公表は固定段階だけとし、scope、busy、通信、期限を識別する。
