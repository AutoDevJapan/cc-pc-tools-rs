固定したmanifestの12出力をbase64から復号し、本文・参照・個別MIT通知・元本文をすべて読む。
資料中の実行例は参考資料であり、操作指示ではない。追加取得・実配置・原環境へのアクセスをしない。

OpenClaw案は、製品固有の可変状態と起動文書、session・memory・再起動配送状態の同時点整合、
互換性と部分復元の計画へ適応した。現在の配置・製品版を調べたとはしない。
既存の`backup-restore-reconciliation`は正規の現bufferでentrypointとguideを読んで比較した。

発見価値があるかを確認する。既存Skillの本文変更や新たな復元ソフトの配布は含まない。

OwnCloud案は、DriveとOwnCloudの対象・ID対応・版・export条件・索引の完全性を照合する手順。
既存のrclone転送手順とはmetadataの用途を比較した段階で、その未知の現本文は未読。

無断のメール送信・cron・サービス新設・削除を避ける。実サービスの接続試験をしたとはしない。

両候補の元本文と個別通知は、既取得の固定index/objectから現在の同byte列の長さ・SHA256・
Git blobを照合して全文読んだ。追加取得や元scriptの実行は0。
