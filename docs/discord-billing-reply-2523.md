## 実際に確認したこと

契約名と契約開始時の表示を確認した。候補のアカウント選択リンクは
HTTP 400の画面になった。その画面のホームリンクから進む操作は、
自動承認審査が「候補という返信だけでは別アカウントの私的な請求情報を
読む許可として不十分」として拒否した。拒否された閲覧は実行していない。

この工程で請求額、請求周期、次回更新日、過去30日の請求履歴は
確認していない。契約変更、追加購入、支払いも行っていない。

担当が作成したChromeタブ2枚は、所有記録のinstance・generation・tabを
inventoryと照合し、`owner_chrome close`で個別に終了した。
どちらもclosed=1、failed=0である。他担当のタブはそのまま保持した。
