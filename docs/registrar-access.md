# ドメイン事業者へのアクセス制限

ドメイン管理はRakkoのみ。ほかの事業者は対象を指定したオーナーの明示依頼なしに表示・ログイン・登録・DNS変更・調査のためにアクセスしない。一般のログイン代行許可、Chromeの保存済み認証、過去のログや担当の推測を対象サイトへの許可にしない。他人・旧勤務先のログインは使わない。

この制限はChrome、CUA、ブラウザCLI、HTTP CLIにも適用する。未知の事業者にも適用する行動上の規則であり、既知のホスト一覧を全事業者の網羅的な一覧と扱わない。

`cc-chrome::registrar` は既知の事業者ホストをURLとして解析し、本人のChromeを開くCLIでは接続前、ジョブのブラウザ転送では要求を上流へ送る前に拒否する。タブ作成、Page.navigate、Target.createTarget、Network.loadNetworkResourceのURL指定を対象とする。大文字、サブドメイン、末尾の点、userinfoを考慮し、無関係なURLのqueryに事業者名が含まれるだけでは拒否しない。拒否後も同じ接続で正当な操作と後片付けを続けられる。

HTTP CLI、ブラウザのクリック・リダイレクト、JavaScriptによる遷移、正規転送を使わないブラウザ経路は、このURL指定の拒否処理だけで完全に遮断できない。共通AGENTSとSkillの制限、通常の実行審査を保つ。将来の対象別の明示許可を環境変数やプロンプト中のURLから自動で推測しない。追加の対象許可が必要なら、その明示依頼と対象を照合したうえで仕組みを更新する。

## ToDo2383の保存済み事故記録の確認

担当20261011-120720-resume-537236、2026-10-11、日本時間。サイトへの再アクセスをせず、担当の保存済みセッションとタブ所有履歴を照合した。

- 12:20:03: お名前.comへの新しいタブの表示操作。
- 12:23:43: 保存済み自動入力後のログインボタン操作。応答でログイン後の画面を確認。
- 12:24～12:26: DNS管理画面の閲覧と対象ドメインの検索操作。
- 12:49:35～12:50:53: 別タブでGoogle連携を進め、許可画面の操作。
- 12:51:05: 新規登録画面と「同意して登録する」ボタンまで到達。登録完了は確認できない。

DNS変更・新規登録未実施という前担当の結果は、実取引や認可の取り消しを証明しない。Google連携の許可操作は登録完了と区別して残す。認証値・旧会社名・画面本文はこの文書へ転記しない。

閉鎖はfinishの集計0だけで認定せず、所有履歴のclosedとinstance・generation・tabの現在inventoryを照合する。オーナーが作ったタブは触らない。

事故の2枚には12:32:42と12:51:28のclosed履歴があり、現在の同じChromeには存在しない。今回追加のタブ閉鎖操作は不要だった。

新規ジョブの読み取り・書き込み指示の両方に制限を追加する。旧ジョブの保存済み依頼、枠を譲った後の再開、コンテキストの引き継ぎ、要約を含め、実際の起動直前に選んだ入力にも最新の制限を追加する。元の入力ファイルを保存し、サンドボックスや読み取り専用の範囲を変更しない。入力が無い場合やUTF-8として読めない場合は、制限文だけで新しい担当を起動しない。
