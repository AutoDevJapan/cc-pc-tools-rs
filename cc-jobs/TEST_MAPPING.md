# Python から Rust へのテスト対応

元の `tests/test_codex_jobs.py` にある unittest メソッド95件をすべて移植しました。`test_tempdir` はテスト用ディレクトリを返す補助関数です。追加の14件では、ヘルプと引数エラー29パターン、Windows終了コード、改行とJSONの項目順、Cargo呼び出し元、共有エラーの再試行、UNCパス、ロック互換性、秘密の扱い、起動失敗、PID再利用、終了時のイベント回収を確認します。

テストは一時フォルダだけを使います。CodexはRust製の偽物に置き換え、OpenCodex・GTO・JevはRuntime traitの偽物で検証します。DiscordのAPIへ直接アクセスする処理はありません。
