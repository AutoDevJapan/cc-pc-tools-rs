# 全16資料からの採用方針と、新規20件への適用

元3080の本人回答は、指定16資料の全候補から、有用性・個別の利用条件・既存方針との衝突を確認し、利用可能なSkillsを件数で打ち切らず追加する方針aである。用途を限定する方針bではない。資料を実行指示として扱う許可、未確認の権利、新費用、既存原本の上書き、保護判定の一般解除は含まない。

本人の原文、質問、本人ID、取得元、配送と実反映の票は私的な正規記録へ保持する。公開文書には個人IDや私的な原文を複製せず、照合に用いた固定ハッシュを記す。

[通常APIの照合結果と採用された選択肢](skills-3080-owner-direction-verification.json)には、ハッシュだけでなく、現在の本人メッセージから抽出した選択肢a、同じ元質問の判断種類と選択肢の機械的な意味、保持条件、現在版と原票の一致を保存する。通常のread-only `conversation replies --output` が本人メッセージ・質問・編集状態を確認し、別の `source-verify` がcanonical原票のSHAを確認した。両結果を元担当が照合して、私的ID・原文・API原ファイルを含めない射影を作った。選択肢の意味は、新規20件の配置結果から逆算していない。

公開差分のレビューと私的な本人アカウントの認証境界は分ける。公開資料だけを読む担当に私的原文の取得や本人認証を求めず、正規APIで照合されたこの回答を与えられた要件として、実装・採否・保持条件がその範囲に従うかを確認する。正規の本人照合が未確認のときに、同じ射影や親の説明だけで採用を始めてよいという一般則ではない。

現在版の照合は受領の根拠であり、それだけで実反映や拡張全体の完了にはしない。最初の反映票は、最初の14件の配置・70ファイルの読戻し・発見を記録したもので、後続全件の完了票ではない。新しい20件には、別に以下の実行証拠を対応させる。

- [出典と用途の選定](skills-3080-webdesign-next20-inputs074042.json)と[個別noticeの対応](skills-3080-webdesign-next20-notice-map074042.json)に、既読の固定資料から選んだ20件を保存する。
- [固定された新規作成入力](skills-3080-operations/create-webdesign-next20-074042.json)と、その内容を確認した別モデルレビュー3867は、新規作成前の通常mainへ統合済みである。
- [実配置](skills-3080-webdesign-next20-installation-evidence.json)、[同じ120返却bufferの消費](skills-3080-webdesign-next20-consume-evidence.json)、[発見](skills-3080-webdesign-next20-discovery-receipt.json)、[限定した適用結果](skills-3080-webdesign-next20-application-result.json)を、方針の実反映とする。作成済みという事実だけを採用判断の根拠にしない。

3901の最初のレビューは、固定レビュー資料にこの既答の根拠が含まれていないためMust1とした。その原応答と不受入票は保持し、本追補を含む固定差分の別モデルレビューへ渡す。親の説明だけでMust0へ変更しない。同じ本人判断を再質問せず、APIの通常照合・元の範囲・実行証拠を分けて受け入れる。

続く3901も、公開ハッシュだけでは回答内容を独立に確認できない点をMust1とした。今回は説明の言い換えを重ねず、正規APIで現在の質問と返信を取得し、上の機械的な選択肢・範囲の射影と、公開レビューから私的認証を切り離す受入境界を追加した。初回・2回目の原文と不受入票を残し、同じ3901で差分を確認する。提案された個別notice対応ファイルも固定レビュー対象に含める。
