# youtube-dailyを発信部へ表示する先行修復

元ToDo3103・Issue289。2026-10-21 10:56の本人指示により、youtube-dailyの
古い別欄配置をこの製品について更新する。名前・他製品の帰属・現在のPrd画面を保つ。
元PR302と未完了の分類・プライバシー修正は別に保持する。

受入条件:

- 通常表示と`masked_metadata`の両方で、youtube-dailyを発信部へ一度表示する。
- 完了した過去の登録総数を現在の担当数にしない。記録、起動待ち、実行中と未取得を区別する。
- 同じジョブを主担当・親子・関連ToDoから重複して現在の実行へ数えない。
- 監督のタイトルに製品名が含まれていても、その製品の作業へ移さない。
- 非表示本文・パス・既存privacy/admissionと旧membershipの原記録を保つ。
- 現在のPrdの応答を改行だけ正規化したSHA256
  `335ad98840c97d0767b8e78bf8166f48c6044a1f2d1a8a25c3bdea831320abf9`を保つ。
- 必要な回帰と別モデルレビュー・同じ最終ソースのCIを確認し、通常マージ後に
  既存Prdへ一度配布して実APIと本人Chrome画面を照合する。

変更はConsoleの投影と既存asset選択に限定する。共有製品識別・優先順位・収集器の
広い修復は先行配布の前提にしない。検査はlocalai-web-rsと直接の利用側に絞り、
既存Prdのページ保持Redは受領済み3219の固定測定を保持する。
